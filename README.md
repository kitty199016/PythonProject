# Название проекта
Виджет, который показывает несколько последних успешных банковских операций клиента. Вам доверили реализовать этот проект, который на бэкенде будет готовить данные для отображения в новом виджете.

## Технологии
Python 3.12

Для установки и запуска проекта, необходим Python 3.12

1. Клонируйте репозиторий:
```

## Тестирование и качество кода

Для обеспечения надежности приложения проект покрыт модульными тестами и проверяется статическими анализаторами.

### Инструменты разработки
Перед запуском тестов и проверок убедитесь, что у вас установлены все зависимости для разработки:
```bash
pip install pytest mypy flake8
```
Декоратор @log Декоратор автоматически логирует начало и конец выполнения функций, их возвращаемые значения, 
а также перехватывает и записывает возникшие ошибки.
---

### 1. Запуск модульных тестов (Pytest)

В качестве основного фреймворка тестирования используется **pytest**. Тесты проверяют как корректную работу функций при валидных данных, так и обработку исключений при передаче неверных форматов.

* **Запуск всех тестов в тихом режиме:**
  ```bash
  pytest
  ```
* **Запуск с подробным выводом (рекомендуется):**
  Выводит названия каждого теста и статус его выполнения.
  ```bash
  pytest -v
  ```
* **Запуск конкретного файла тестов:**
  ```bash
  pytest tests/test_processing.py -v
  ```

---

### 2. Статический анализ типов (Mypy)

В проекте используется строгая типизация. Все функции и тест-кейсы должны иметь стопроцентную аннотацию типов без пропусков (`[no-untyped-def]`).

Для проверки аннотаций типов запустите команду:
```bash
mypy .
```
*Код считается прошедшим проверку только при выводе сообщения: `Success: no issues found`.*

---

### 3. Линтинг и форматирование (PEP 8)

Код проверяется на соответствие стандарту **PEP 8** (например, отсутствие лишних или недостающих пустых строк `E302`, корректность отступов и длины строк).

Для проверки стиля кода выполните:
```bash
flake8 .

## ✨ Новые генераторы и функции

В этой версии добавлены инструменты для эффективной потоковой обработки банковских транзакций и генерации тестовых данных. Все функции используют `yield` и возвращают итераторы, что минимизирует потребление оперативной памяти.

### 📝 Описание сигнатур

*   **`transaction_descriptions(transactions: list[dict]) -> Iterator[str]`**
    Принимает список словарей с транзакциями и поочередно возвращает строковое описание (`description`) для каждой операции.
*   **`filter_by_currency(transactions: list[dict], currency: str) -> Iterator[dict]`**
    Принимает список словарей с транзакциями и возвращает итератор, который выдает только те транзакции, где валюта (`operationAmount -> currency -> code`) соответствует заданной.
*   **`card_number_generator(start: int, end: int) -> Iterator[str]`**
    Генерирует номера банковских карт формата `XXXX XXXX XXXX XXXX` в заданном числовом диапазоне от `start` до `end` включительно.
