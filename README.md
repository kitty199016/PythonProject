## ✨ Новые генераторы и функции

В этой версии добавлены инструменты для эффективной потоковой обработки банковских транзакций и генерации тестовых данных. Все функции используют `yield` и возвращают итераторы, что минимизирует потребление оперативной памяти.

### 📝 Описание сигнатур

*   **`transaction_descriptions(transactions: list[dict]) -> Iterator[str]`**
    Принимает список словарей с транзакциями и поочередно возвращает строковое описание (`description`) для каждой операции.
*   **`filter_by_currency(transactions: list[dict], currency: str) -> Iterator[dict]`**
    Принимает список словарей с транзакциями и возвращает итератор, который выдает только те транзакции, где валюта (`operationAmount -> currency -> code`) соответствует заданной.
*   **`card_number_generator(start: int, end: int) -> Iterator[str]`**
    Генерирует номера банковских карт формата `XXXX XXXX XXXX XXXX` в заданном числовом диапазоне от `start` до `end` включительно.

*   Декоратор @log Декоратор автоматически логирует начало и конец выполнения функций, их возвращаемые значения, а также перехватывает и записывает возникшие ошибки.

### 1. Единый интерактивный UI (`src/main.py`)
Реализован пошаговый консольный менеджер (`main()`), который координирует работу всех модулей проекта и обеспечивает:
* Выбор источника данных (JSON/CSV/Excel) с автоматической валидацией пользовательского ввода.
* Регистронезависимый повторный запрос статуса при ошибочном вводе пользователя.
* Динамическое управление цепочкой фильтрации (по статусу, дате, валюте и ключевым словам).
* Полную архитектурную декомпозицию (цикломатическая сложность функции `main` снижена до минимума в соответствии с PEP 8).

### 2. Мультиформатное чтение данных (`src/table_utils.py` и `src/utils.py`)
Добавлена поддержка обработки плоских табличных файлов:
* **`read_csv()`**: Построчный импорт транзакций через встроенный модуль `csv.DictReader`.
* **`read_excel()`**: Импорт файлов XLSX на базе библиотеки `pandas` с автоматическим приведением пустых ячеек `NaN` к системному типу `None`.
* **Нормализация данных**: Реализован внутренний конвертер плоских структур во вложенные JSON-объекты, защищающий модули фильтрации от ошибок `KeyError`.

### 3. Интеграция внешнего валютного API (`src/external_api.py`)
* Функция `get_transaction_amount_in_rub()` теперь автоматически определяет валюту транзакции.
* При обнаружении `USD` или `EUR` приложение выполняет асинхронный сетевой запрос к *Exchange Rates Data API* с использованием секретного ключа доступа (`EXCHANGE_RATES_API_KEY`) из файлов `.env`.
* Возвращает точную сумму, сконвертированную в рубли по актуальному курсу. Рублевые операции обрабатываются мгновенно локально.

### 4. Расширенный текстовый поиск и статистика (`src/search_data.py`)
* **`process_bank_search()`**: Регистронезависимый поиск подстроки в поле `description` с использованием предварительно скомпилированных регулярных выражений (`re.compile`), экранирующих спецсимволы.
* **`count_operations_by_counter()`**: Оптимизированный инструмент аналитики, вычисляющий точное количество финансовых операций по заданным категориям с помощью высокоэффективного класса `collections.Counter`.
