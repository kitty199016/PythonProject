# Название проекта
Виджет, который показывает несколько последних успешных банковских операций клиента. Вам доверили реализовать этот проект, который на бэкенде будет готовить данные для отображения в новом виджете.

## Технологии
Python 3.12


## Разработка

### Требования
Для установки и запуска проекта, необходим Python 3.12

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/kitty199016/PythonProject
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
